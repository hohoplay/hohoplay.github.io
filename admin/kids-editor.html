⚙️ 저장 설정 (GitHub 연결)
토큰 만드는 법 (무료, 한 번만)
  1. GitHub 토큰 만들기 페이지를 열어요.
  2. Token name은 아무거나(예: kids-editor), Expiration은 90일~1년으로 정해요.
  3. Repository access → Only select repositories → 이 사이트 저장소 하나만 선택해요.
  4. Permissions → Repository permissions에서 Contents: Read and write, (선택) Actions: Read and write로 바꿔요.
  5. Generate token → 나온 github_pat_... 값을 위 칸에 붙여넣어요. 공용 PC에서는 쓰지 마세요.
토큰이 없으면 보기와 수정(임시 저장)만 되고, 저장하려면 토큰이 필요해요. 토큰이 없을 때는 "JSON 내려받기"로 파일을 받아 직접 올릴 수도 있어요.
