Section 01

승인을 위한 기본 수칙 및 지침

웹사이트 콘텐츠의 기반 조성

"준비 중(Under Construction)" 안내 페이지, 더미(Dummy) 글, 빈 페이지는 승인 거절의 주요 원인이다. 분량이 충분하고 실질적인 정보를 담은 콘텐츠를 배치해야 한다.

독창적인 고품질 콘텐츠 작성

  • 표절이나 타 사이트 복사 글은 절대 금물 — 직접 작성한 고유한 콘텐츠여야 한다.
  • 얕은 정보를 담은 페이지 여러 개보다, 깊이 있고 유용한 고품질 포스트 몇 개가 훨씬 효과적이다.
  • 문법 오류나 오타를 줄여 글의 전문성을 높인다 (필요 시 문법 검사 도구 활용).

사이트 내 중복 콘텐츠 지양 및 내비게이션 최적화

  • 여러 페이지에 동일한 내용을 복사해 붙여넣는 행위는 피한다.
  • 관련 글끼리는 내부 링크(Internal Linking)로 연결한다 — SEO에도 도움이 된다.
  • 모든 기기(PC·모바일 등)에서 메뉴·내비게이션 바의 위치와 동작이 일관되고 직관적이어야 한다.

금지 콘텐츠 규정 준수 및 트래픽 관리

⚠️ 엄격히 금지되는 콘텐츠
성인용, 폭력적, 위험 물질 제작 방법 등 부적절하거나 위험한 콘텐츠.
  • SNS·메신저 등을 통한 정당한 링크 공유로 방문자를 유치한다 (봇·조회수 구매 등 불법 가짜 트래픽 금지).
  • 광고 게재 및 수익 창출 사실을 명시하는 개인정보 처리방침(Privacy Policy) 페이지를 반드시 구비한다.
Section 02

거절 1순위 — '가치가 낮은 콘텐츠' 7가지 유형

단순히 글자 수가 부족해서가 아니라, 아래 7가지 사유로 거절 메일을 받는 경우가 대부분이다.

1고유 콘텐츠 부족나만의 독창적인 내용이나 분석이 없는 글
2요약·번역·재작성단순 타 사이트 글 요약, 기계적 번역, 재가공 글
3AI 대량 유사 글생성형 AI로 대량 발행된 유사 문서
4짧은·빈 페이지내용이 거의 없거나 형식적인 빈 페이지
5미디어만 있고 설명 부족이미지·동영상만 있고 텍스트 설명이 부실한 글
6방문 이유 약함유익함이나 명확한 정보 가치를 제공하지 못하는 글
7찾기 어려운 구조카테고리 분류가 모호하거나 탐색 구조가 복잡한 사이트
Section 03

기존 URL 진단 및 정리 기준

무작정 새 글을 쓰기보다, 기존 URL을 아래 4등급으로 먼저 진단하고 정리하는 작업이 우선이다.

A
유지
콘텐츠 가치가 높고 트래픽 및 전환 상태가 양호함
조치 → 현재 상태 유지
B
보강
주제의 잠재력은 있으나 내용이 다소 부족함
조치 → 콘텐츠 보강, 내부 링크·사이트 구조 개선
C
통합 → 301 리다이렉트
내용이 유사하거나 중복된 글이 여러 개 존재
조치 → 대표 페이지 하나로 통합 후 301 리다이렉트
D
삭제·제외
콘텐츠 가치가 낮고 트래픽·전환이 거의 없음
조치 → 글 삭제 또는 검색 노출(색인) 제외

진단 체크리스트

  • 이 페이지는 A~D 중 어디에 해당하는가?
  • C 등급이라면, 통합할 대표 페이지는 어디로 정할 것인가?
  • D 등급이라면, 완전 삭제할지 색인 제외(noindex)만 할지 정했는가?
  • B 등급 보강 시, 어떤 내부 링크를 새로 연결할 것인가?

크롤러 연결 상태 (섹션 01 대응)

완료 내비게이션 일관성전체 페이지(홈·게임·미니게임·투표·퀴즈·운세·정책 등) nav 메뉴와 약관 드롭다운을 완전히 통일함.
완료 내부 링크로 콘텐츠 연결홈 → 게임/미니게임/투표/퀴즈/운세, 게임 → 다른 게임 9개, 이렇게 어디서 진입해도 사이트 전체를 발견할 수 있는 구조로 재구성.
완료 빈 페이지·더미 텍스트 제거각 게임 설명·조작가이드·공략FAQ·킥포인트를 실제 게임 로직 기반으로 채움. "이미지를 터치하세요" 같은 의미 없는 반복 문구도 제거.
완료 개인정보 처리방침 구비광고 게재·쿠키 수집 관련 조항까지 포함해 이미 게시되어 있음.

거절 사유 7가지 대조 (섹션 02 대응)

완료 ① 고유 콘텐츠 부족 / ⑥ 방문 이유 약함게임마다 실제 메커니즘(등장 시점·난이도 상승 방식·종료 조건)을 담은 "킥포인트" 문단과 FAQ 5개씩 신규 작성.
완료 ④ 짧은·빈 페이지정적 폴백 텍스트 분량을 지속적으로 보강(홈페이지 기준 대폭 확충).
완료 ⑦ 찾기 어려운 구조게임을 장르가 아닌 상황 기준(결정 못 할 때·5초 때우기·친구랑 둘이 등)으로 재분류하고, "계속 늘어나요" 신선도 신호도 추가.
해당 없음 ② 요약·번역·재작성 / ③ AI 대량 유사 글 / ⑤ 미디어만 있고 설명 부족자체 제작 게임 콘텐츠라 해당 사유 자체가 발생하지 않는 영역.

URL 진단 매트릭스 적용 (섹션 03 대응)

부분 완료 C등급(통합 → 301 리다이렉트) 대체 적용GitHub Pages는 정적 호스팅이라 서버 차원의 진짜 301은 불가능. 대신 game1.html 같은 의미 없는 URL을 hoya-typing-rpg.html 등 의미 있는 슬러그로 복제하고, 원본의 canonical을 새 슬러그로 지정해 구글이 새 URL을 대표 페이지로 인식하게 처리(10개 게임 전체 적용). 진짜 301만큼 깔끔하진 않지만 실질적 효과는 유사함.
완료 내부 링크도 새 URL로 완전 갱신게임 간 크로스링크, 홈페이지 그리드, 검색 데이터(encyclopedia_index.json)까지 전부 새 슬러그로 일괄 갱신해 링크 파워가 분산되지 않도록 처리.
